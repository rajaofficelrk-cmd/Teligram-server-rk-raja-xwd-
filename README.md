## ⚙️ Installation

Install dependencies:

pip install -r requirements.txt

## 🔐 Environment Variables

SECRET_KEY=your_secret_key

ADMIN_PASSWORD=your_password

TELEGRAM_BOT_TOKEN=your_bot_token

TELEGRAM_CHAT_ID=your_chat_id

Never share your Telegram bot token.

## 🌐 Render Deployment

Build Command:

pip install -r requirements.txt

Start Command:

gunicorn app:app

Add all environment variables in Render Settings.

## 📱 Local Run

python app.py

Open:

http://localhost:5000

## ⚠️ Important

- Add your Telegram bot to the destination chat.
- Make sure the bot has permission to send messages.
- Use only approved recipients.
- Sending requires a manual button press.
- Do not use this project for spam.
